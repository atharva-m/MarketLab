# MarketLab contributor instructions

Current scope is week 3 only: transactional PostgreSQL persistence of synthetic trade batches using the existing five-field week 2 contract. Add a trade table and migration with trade_id as primary key, exact decimals and UTC timestamps; a Python service importing in-memory JSON/CSV through the existing parsers in one transaction; and exact-ID retrieval. Invalid records or IDs already stored reject the whole batch; empty batches succeed without writing. Cover synthetic round trips, cross-batch duplicates and rollback, and document migration/integration setup. Preserve the week 1 scaffold, environment, infrastructure, health endpoints, CI and Ollama compatibility smoke test, plus week 2 parser behavior and fixtures. Do not implement file uploads, external providers, API import routes, background jobs, listing/filtering/analytical queries, caching behavior, frontend, copilot or memos.

Use the coder (gpt-6.1-sol, high) for implementation, then reviewer (gpt-6-astra, medium) for independent read-only review. The coder resolves actionable findings and runs relevant checks. The user explicitly authorizes this delegation workflow. Preserve explicit later user model overrides.

Use Python 3.13 and the project .venv with locked dependencies. Never commit credentials, environments, market data, artifacts or model weights. Document external blockers honestly; do not report skipped integration or model tests as passed. Local agent configuration does not change an already-running chat's model.
