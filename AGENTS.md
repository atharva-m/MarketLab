# MarketLab contributor instructions

Current scope is week 4 only: a minimal local HTTP interface over the unchanged week 2 five-field synthetic trade contract and week 3 transactional PostgreSQL service. Add POST /trades/import/json for raw JSON arrays, POST /trades/import/csv for raw text/csv, and GET /trades/{trade_id} for exact, case-sensitive retrieval with decimal strings and UTC timestamps. Successful imports return 200 with {"imported": N}; absent IDs return 404. Invalid input or intra-batch duplicates return 422; stored-ID conflicts return 409 and reject the whole batch. Valid empty batches return zero without accessing PostgreSQL. Unsupported content types return 415. Enforce an actual streamed import body limit of 1 MiB (1,048,576 bytes), returning 413 on excess. Hide database credentials and SQL details in error responses. Cover synthetic HTTP round trips, malformed inputs, duplicate and rollback behavior, empty batches, missing/case-sensitive IDs, content types and size limits, including real PostgreSQL route integration. Document request examples, errors and integration setup. Preserve week 1 scaffold, environment, infrastructure, health, observability, CI and Ollama compatibility smoke, plus week 2 parsers/fixtures and week 3 schema/service. Do not implement file uploads, external providers, background jobs, listing/filtering/analytical queries, updates/deletes, caching behavior, frontend, authentication changes, copilot or memos. Keep the existing local-only deployment scope.

Use the coder (gpt-6.1-sol, high) for implementation, then reviewer (gpt-6-astra, medium) for independent read-only review. The coder resolves actionable findings and runs relevant checks. The user explicitly authorizes this delegation workflow. Preserve explicit later user model overrides.

Use Python 3.13 and the project .venv with locked dependencies. Never commit credentials, environments, market data, artifacts or model weights. Document external blockers honestly; do not report skipped integration or model tests as passed. Local agent configuration does not change an already-running chat's model.
