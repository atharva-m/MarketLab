Retain all filters across requests and change only after_id. Print each existing JSON page envelope to stdout, one per line, preserving decimal strings and UTC timestamps. Stop when next_after_id is null or the page cap is reached; preserve the final envelope's cursor so the caller can resume. Use finite request timeouts. Fail clearly on HTTP, connection and malformed-response errors with a nonzero exit status, diagnostics on stderr and no sensitive details. Reject non-progressing or inconsistent pagination responses rather than silently looping. Keep the client local-only with a loopback default and support the local API's configurable port.

Cover filter retention, timestamp URL encoding, page caps, full/final/empty pages, cursor progression, serialization and failure handling with offline tests.
